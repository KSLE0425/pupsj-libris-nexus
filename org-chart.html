⚙️ Business Services Layer (`app/Services`)
AISuggestionService AI / ML
Integrates with Google Gemini API & Python FastAPI microservice for personalized book recommendations and purchase gap analysis.
BorrowEligibilityService Rules
Validates patron loan eligibility: checks active patron bans, overdue loan limits, unpaid penalty thresholds, and max loan caps.
KohaApiService Sync
Handles two-way REST API integration with external Koha ILS server for syncing bibliographic items and patron statuses.
PenaltyCalculationService Finance
Calculates overdue fees based on collection category fine rates, overdue grace days, and weekend/holiday exclusions.
ReceiptPrinterService Hardware
Generates ESC/POS formatted thermal receipt slips for self-service kiosk checkout and return transactions.
TrendTrackerService Analytics
Aggregates circulation metrics, peak borrowing hours, trending academic topics, and underutilized library resources.

        Elig -->> Ctl: Eligible
        Ctl ->> DB: Create KioskOtpCode
        Ctl ->> Mail: Send OTP to patron email
        Patron ->> Kiosk: Enter OTP
        Kiosk ->> Ctl: Verify OTP code
        Ctl -->> Kiosk: Session Approved
        Patron ->> Kiosk: Scan Book QR / Barcode
        Kiosk ->> DB: Check book availability
        DB -->> Kiosk: Book Available
        Patron ->> Kiosk: Confirm checkout
        Kiosk ->> DB: Insert BookUsage & update Book status
        Kiosk ->> Print: Print transaction receipt
        Print -->> Patron: Thermal Paper Slip
